Connect, then create your workspace

DexterOS runs entirely on Cloudflare: Pages hosts the app, D1 stores the database and R2 stores uploaded icons, wallpapers and avatars. Bindings are configured in your Cloudflare dashboard — never in this repository.

Wiring checks

Dashboard refusing to add bindings with “bindings of this project are managed through wrangler.toml”? That means a Wrangler config file is committed at the project root. Delete it (keep only docs/wrangler.example.toml), push, and trigger a new deployment — the settings become editable again.

Add these bindings in Cloudflare → Workers & Pages → your Pages project → Settings → Functions:
TypeVariable nameValue
D1 databaseDBYour D1 database
R2 bucketMEDIAYour R2 bucket

After saving the bindings, redeploy (or re-run the build) and press “Re-check”. No account id, database id, bucket name or token is ever hard-coded in the app.
